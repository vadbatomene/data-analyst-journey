# Plan de formation Data Analyst

Durée prévue : environ 12 mois. Les durées sont des estimations, à ajuster selon mon rythme.

Règles : je coche une case seulement quand j'ai pratiqué la notion dans un exercice. Chaque phase se termine par un projet. Le noyau prioritaire est SQL, Excel, un outil BI, Python/pandas et les bases de statistiques.

## Phase 1 : SQL (environ 2 à 3 mois)
- [x] SELECT, WHERE, ORDER BY, LIMIT
- [x] GROUP BY, HAVING
- [x] Jointures (INNER JOIN, LEFT JOIN)
- [x] Sous-requêtes et CTE
- [x] Fonctions de fenêtrage (ROW_NUMBER, RANK, SUM OVER, LAG, LEAD, NTILE)
- [x] CASE WHEN
- [x] Dates (YEAR, MONTH, DATE_FORMAT, DATEDIFF)
- [x] Texte (LIKE, CONCAT, UPPER, TRIM, SUBSTRING)
- [x] Jointures multiples (3 tables ou plus)
- [x] DISTINCT et COUNT(DISTINCT)
- [x] BETWEEN, IS NULL, NULLIF, CAST
- [x] UNION et UNION ALL
- [x] Self join
- [x] Modélisation (PRIMARY KEY, FOREIGN KEY, types de données, normalisation)
- [x] Vues (CREATE VIEW)
- [x] Index et EXPLAIN
- [x] UPDATE, DELETE, ALTER TABLE
- [x] Objets programmables (variables, procédures, fonctions, déclencheurs, événements)
- [ ] Analyses métier en SQL : entonnoir de conversion, cohortes, segmentation RFM, évolution mois par mois
- [ ] Projet : analyse d'une base de ventes

## Phase 2 : Excel / Google Sheets (environ 1 mois)
- [ ] Formules de base et références (relatives, absolues)
- [ ] Formules conditionnelles (SI, SI.CONDITIONS, SIERREUR)
- [ ] Fonctions de recherche (RECHERCHEX, INDEX et EQUIV)
- [ ] Fonctions d'agrégation conditionnelles (SOMME.SI.ENS, NB.SI.ENS, MOYENNE.SI.ENS)
- [ ] Fonctions de texte et de dates
- [ ] Tableaux croisés dynamiques et segments
- [ ] Nettoyage de données (doublons, valeurs vides, formats)
- [ ] Power Query (import et transformation)
- [ ] Mise en forme conditionnelle et validation de données
- [ ] Graphiques et tableau de bord Excel
- [ ] Google Sheets (QUERY, ARRAYFORMULA, IMPORTRANGE)
- [ ] Projet : tableau de bord de suivi des ventes

## Phase 3 : Python (environ 3 mois)
- [ ] Installation, environnement virtuel, pip, Jupyter
- [ ] Bases du langage (variables, types, listes, dictionnaires)
- [ ] Conditions, boucles, fonctions
- [ ] Gestion des erreurs et lecture/écriture de fichiers (CSV, Excel, JSON)
- [ ] NumPy (tableaux, calculs vectorisés)
- [ ] pandas : import, inspection, sélection et filtres
- [ ] pandas : valeurs manquantes, doublons, types, dates
- [ ] pandas : groupby, agrégations, pivot_table
- [ ] pandas : merge, join, concat
- [ ] pandas : apply et fonctions personnalisées
- [ ] Expressions régulières (regex)

- [ ] Visualisation (matplotlib, seaborn, plotly)
- [ ] Analyse exploratoire (EDA)
- [ ] Séries temporelles simples (tendance, saisonnalité, évolution)
- [ ] Analyses métier en Python : cohortes, entonnoir, segmentation RFM
- [ ] Récupération de données (API, notions de web scraping)
- [ ] Projet 1 : nettoyage et analyse d'un fichier CSV

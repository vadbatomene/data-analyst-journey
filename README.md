## Structure du dépôt

- `journal/` : une note par jour de travail (vu, difficultés, exercices, suite)

- `02-excel/` à `05-bi/` : exercices et projets de chaque phase

- La durée réelle de chaque phase est notée pour comparer mon rythme au plan.
